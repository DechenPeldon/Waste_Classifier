About Our Project

Project Overview

The Smart Waste Classifier is an AI-powered web application designed to help users properly identify and dispose of waste materials. Using advanced computer vision and deep learning technology, our system can automatically classify waste into 9 different categories with high accuracy.

Our mission is to make recycling easier and more accessible for everyone, contributing to a cleaner and more sustainable environment. By providing instant classification and detailed disposal information, we empower users to make informed decisions about waste management.
